# 第二套：WPF / MVVM 企业级框架学习路线

> **前置条件：先学完 `../../winformDemo/教程/00` → `10`。**
> 本套默认你已经理解分层、组合根、依赖注入、后台服务、事件封送与仓储抽象。
> 本套只回答一个问题：**表现层换成 WPF + MVVM 之后，哪些东西必须重写，哪些东西一行都不用改？**

## 先做一个实验，再往下读

```bash
cd Winform-WPF
diff winformDemo/Core/Models.cs                       wpfDemo/Core/Models.cs
diff winformDemo/Core/Abstractions.cs                 wpfDemo/Core/Abstractions.cs
diff winformDemo/Infrastructure/CalibrationService.cs wpfDemo/Infrastructure/CalibrationService.cs
diff winformDemo/Infrastructure/SimulatedModbusClient.cs wpfDemo/Infrastructure/SimulatedModbusClient.cs
diff winformDemo/Infrastructure/JsonMeasurementRepository.cs wpfDemo/Infrastructure/JsonMeasurementRepository.cs
diff winformDemo/Application/AcquisitionService.cs    wpfDemo/Application/AcquisitionService.cs
diff winformDemo/appsettings.json                     wpfDemo/appsettings.json
```

Windows PowerShell 用 `Compare-Object (Get-Content a) (Get-Content b)`，或 `fc /b a b`。

**七条命令全部无输出。** 领域层、基础设施层、应用层、配置文件——逐字节相同。这就是第一套 10 章所有设计决定的验收证据。

两套唯一不同的代码：

| 位置 | WinForms | WPF |
|---|---|---|
| 组合根 | `Program.cs` | `App.xaml.cs`（`OnStartup`） |
| 表现层 | `Presentation/MainForm.cs` | `Views/MainWindow.xaml(.cs)` + `ViewModels/MainViewModel.cs` |
| 项目文件 | `UseWindowsForms=true` | `UseWPF=true` + `CommunityToolkit.Mvvm` + 补 `System.IO` 隐式 using |

## 环境

- Windows + .NET 8 SDK；NuGet 还原 `Microsoft.Extensions.Hosting 8.0.1` 与 `CommunityToolkit.Mvvm 8.4.2`。
- 不需要串口设备，业务层与第一套完全相同。

## 三条命令

```bash
cd wpfDemo
dotnet build
dotnet run -- --self-test     # 不弹窗口，验证装配
dotnet run                    # 打开窗口
```

自检预期同样是 `OK | channels=8 | ... | 通道1 raw=2700 -> 25.00 mm`。

## 概念映射表（先有个心理坐标）

| WinForms 第一套 | WPF 第二套 | 本质 |
|---|---|---|
| `MainForm`（控件 + 事件处理） | `MainWindow.xaml`（View） + `MainViewModel`（状态与命令） | 界面与界面逻辑分离 |
| `BuildUi()` 用 C# 堆控件 | XAML 声明式描述界面 | 声明 vs 命令式 |
| `uiTextBox1.Text = ...` | `Text="{Binding ProjectName}"` | 数据绑定取代手工赋值 |
| `BindingList<T>` + `DataSource` | `ObservableCollection<T>` + `ItemsSource` | 集合变更通知 |
| `ResetBindings()` | `ObservableObject` 属性通知 | 属性级刷新 |
| `button.Click += OnSaveClick` | `Command="{Binding SaveCommand}"` | `ICommand` 取代事件处理 |
| `SynchronizationContext.Current` | `DispatcherSynchronizationContext` | 同一个抽象，不同实现 |
| `[DisplayName("通道")]` | `<DataGridTextColumn Header="通道" .../>` | 列定义方式不同 |
| `Program.cs` 组合根 | `App.xaml.cs` 组合根 | 装配位置随宿主变 |
| `Application.Run(form)` | `window.Show()` | 消息循环由 WPF 托管 |

📌 **最重要的一列是「本质」**：技术名词换了，但「通知 UI 数据变了」「把用户动作转成命令」「把后台数据封送回 UI 线程」这三件事没变。学 WPF 时不断回看这张表，会省力很多。

## 目录结构

```
wpfDemo/
├── WpfDemo.csproj
├── appsettings.json            ← 与 winformDemo 逐字节相同
├── App.xaml / App.xaml.cs      ⭐ 组合根 + 应用生命周期
├── Core/                       ← 逐字节相同
├── Infrastructure/             ← 逐字节相同
├── Application/                ← 逐字节相同
├── ViewModels/
│   └── MainViewModel.cs       ⭐ 状态 + 命令 + 封送
├── Views/
│   ├── MainWindow.xaml        视图（纯声明）
│   └── MainWindow.xaml.cs     code-behind 只有 3 行有效代码
└── 教程/                       本套 11 篇
```

## 章节安排

| 章 | 主题 | 你要带走的东西 |
|---|---|---|
| 01 | 先跑起来 | 能 build / 自检 / 运行，能说出数据从哪来到哪去 |
| 02 | MVVM 三角 | Model / View / ViewModel 的职责边界，code-behind 该多薄 |
| 03 | 数据绑定与 `ObservableObject` | `INotifyPropertyChanged`、源生成器、`{Binding}` |
| 04 | 命令与 `ICommand` | `AsyncRelayCommand`、CanExecute、与 Click 事件对照 |
| 05 | 集合与 `ObservableCollection` | 集合通知、UI 线程约束、与 BindingList 对照 |
| 06 | 依赖注入与 ViewModel 定位 | `App.xaml.cs` 组合根、构造函数注入、生命周期 |
| 07 | XAML 与布局 | Grid、DataGrid、样式资源、声明式 UI |
| 08 | 业务层零改动 ⭐ | 用 diff 证明分层价值，逐层对照表 |
| 09 | 跨线程与 Dispatcher | `SynchronizationContext.Post` 在 WPF 的行为、取消订阅 |
| 10 | 进阶路线与总复盘 | 导航、对话框、单元测试、Prism、两套总复盘 |

每章同样有「概念 → 读代码 → 🧪 动手实验 → 自测 → 对照」。

> 记一句口诀：**View 只负责长什么样，ViewModel 只负责状态和命令，Model/Service 负责业务。**
